# Welcome to Apodify Docs

## About

**Apodify** is a Python tool designed to **enhance and enrich** the data returned by NASA's Astronomy Picture of the Day (**APOD**) API.

NASA's APOD API provides beautiful daily images and basic metadata. This tool goes a step further by fetching that data, analyzing it, and adding **additional insightful properties** like dominant color palettes, media characteristics, and more.

---

> ⚠️ **Heads up!**  
> This project is currently under active development and refactoring.  
> Interfaces and features may change without notice.

## What Can It Do?

- Fetch data directly from the NASA APOD API
- Analyze images to extract color palettes
- Extend metadata with custom properties
- Easily plug into existing Python workflows

Whether you're building a dashboard, training an AI model, or just love astronomy and data, this tool can help you get more out of every APOD.

## Why Use This Tool?

The official APOD API is great but limited in scope. If you've ever needed more detailed or visual metadata for each day's image, this tool fills in the gaps.

Extended APOD helps transform raw API responses into richer, more usable data.
